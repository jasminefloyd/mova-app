# Connection logos

These marks identify the services a stylist connects in Settings › Connections. They belong to their owners
(Stripe, Google, Meta, Apple) and are used only to name those services.

- `google.svg`, `gcal.svg`, `meta.svg`, `apple.svg`: from the Iconify "logos" set (svg-logos, CC0 1.0).
- `stripe.svg`: the Stripe "S" path from Simple Icons (CC0 1.0) on Stripe's brand purple (#635BFF).

Before a wider launch, swap these for the files in each company's own brand kit and follow its guidelines.
